go-ruby-activerecord is a pure-Go (no cgo) reimplementation of the deterministic core of Rails' ActiveRecord ORM — the query-building, schema-DDL, association, validation and attribute layers that turn a model plus a relation description into SQL, exactly as MRI's activerecord gem does. A lazy, chainable Relation (Where / Order / Joins / aggregates) renders through ToSQL; belongs_to / has_many / has_one / HABTM / :through emit ActiveRecord's exact join geometry; validations produce an Errors object shaped like ActiveModel::Errors; and three dialects (SQLite / PostgreSQL / MySQL) handle quoting and literals. The one thing that genuinely needs a database — executing the SQL — is an injected Adapter host seam (wired to go-ruby-sqlite3 / go-ruby-pg), so the module stays 100% Ruby- and CGO-free while a differential oracle compares its output to ActiveRecord's own Relation#to_sql byte-for-byte.

A faithful port of ActiveRecord's SQL generation and validations in pure Go, cgo disabled, so it cross-compiles and embeds anywhere. It renders relations, association joins, schema DDL and validation messages, and literalizes for three dialects. Correctness is pinned by a differential oracle against the real activerecord gem — generated SQL, errors.full_messages and DDL compared byte-for-byte. It is the ORM backend bound into go-embedded-ruby (rbgo), and a standalone, reusable module — a sibling of go-ruby-sequel in the github.com/go-embedded-ruby ecosystem.
